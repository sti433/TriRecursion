# 🌐 TriRecursion

A clean, minimal, and elegant C# console program that prints all multiples of 3 less than a given number using pure recursion.

## 🔍 Highlights
- 🌱 Simple logic  
- 🌀 Fully recursive  
- 🎯 Perfect for learning recursion  
- 📘 Lightweight and readable  


## 🧠 Concept
The program reduces **N** step-by-step until it reaches a non-valid state,  
then prints every multiple of **3** during its return path.
